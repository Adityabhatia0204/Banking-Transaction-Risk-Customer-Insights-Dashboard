# Banking-Transaction-Risk-Customer-Insights-Dashboard

**Tech:** MySQL · Python · Excel (Pivot) · Power BI

End-to-end project to turn raw banking transactions into clear business insights:
- Monthly trends (txns & amount)
- Regional revenue + avg ticket
- Fraud by channel (rate and volume)
- Risk band distribution (Low/Med/High)
- Top merchants by revenue

## Repo
- `sql/` – DDL + views + data quality checks  
- `notebooks/` – optional data cleaning in Python  
- `excel/` – Excel workbook with pivots (for QA)  
- `powerbi/` – final Power BI dashboard (`.pbix`)  
- `pdf/` – quick preview.
